# GitLab

GitLab é uma plataforma completa de DevOps que permite gerenciar todo o ciclo de vida do desenvolvimento de software. É utilizado na SSP para controle de versão, CI/CD e colaboração em projetos.

## Características Principais

- **Controle de Versão**: Repositório Git para gerenciamento de código-fonte.
- **CI/CD Integrado**: Pipeline de integração e entrega contínua.
- **Gestão de Projetos**: Issues, boards e milestones para acompanhamento de tarefas.
- **Revisão de Código**: Merge requests com ferramentas de revisão.
- **Wiki**: Documentação de projetos.

## Como Usar

Para acessar o GitLab da SSP:

1. Acesse `https://gitlab.ssp.ma.gov.br`
2. Faça login com suas credenciais
3. Navegue pelos projetos ou crie um novo repositório

## Comandos Git Comuns

```bash
# Clonar um repositório
git clone https://gitlab.ssp.ma.gov.br/seu-grupo/seu-projeto.git

# Criar uma nova branch
git checkout -b nome-da-branch

# Enviar alterações
git add .
git commit -m "Descrição das alterações"
git push origin nome-da-branch
```
